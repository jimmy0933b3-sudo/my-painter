# 🎨 My Painter 小小畫家

給 4～8 歲孩子的**離線優先 Android 繪畫遊戲**。第一個主題館是超市樂園。

## 已實作的第一個版本

- 🛒 超市六個區域：水果、蔬菜、麵包甜點、飲品乳製品、雜貨、購物玩具。
- 超市 36 個物品的畫布**直接使用商品選單的原始 emoji 圖**，放大後從同一圖源自動產生輪廓、著色區與透明遮罩；舊版手寫向量線條保留作為舊存檔進度相容用途，**不再繪製於畫布**。
- 36 色調色盤、自由畫筆、畫筆尺寸、點擊填色、復原。
- 真正記錄手指描圖軌跡、依原圖實際外緣判定描線覆蓋率，兩種難度；可切換「原圖參考」檢視彩色來源。
- 自原圖透明像素產生畫筆 Alpha 遮罩，連圖案內的透明洞及獨立區塊都不會畫出界。填色依原圖像素的色相分區，不靠手刻路徑。
- 中文 TTS 語音與提示音，可在家長設定開關。
- 本機自動保存個別作品、畫畫進度；重新開啟可繼續。
- Compose 手機/平板自適應版面；不含廣告、網路與帳戶需求。

> 初版限制：Android Emoji 圖像依裝置內建字型呈現，原圖和畫布用的是**同一個符號來源**。特殊物品使用多個 emoji 組合表示；填色依來源圖片的色彩群組，細碎陰影與複雜形狀可能需要再調校。舊版手刻線條的局部填色無法一對一轉成新原圖的每個像素區域，舊存檔內容仍保留。語音效果仰賴裝置是否有可用的繁體中文 TTS。尚未加入 PNG 匯出、貼紙動畫及進階形狀分割。

## 開發方式

JDK 17、Android SDK API 35、Gradle 8.11.1。

```bash
gradle :app:assembleDebug
gradle :app:testDebugUnitTest
```

開發版安裝位置：`app/build/outputs/apk/debug/app-debug.apk`

## 自動發布

推送 `main` 後，GitHub Actions 會：
1. 使用 JDK 17、Gradle 8.11.1 執行單元測試與 Android Build；
2. **正式發布強制使用四個固定簽章 Secrets**；若缺少或金鑰有誤，Workflow 失敗且不取代現有 APK。PR 只產生 1 天有效的 Debug 測試檔。
3. 發布至單一 [latest Release](https://github.com/jimmy0933b3-sudo/my-painter/releases/tag/latest)，每次覆蓋 `my-painter-latest.apk`；
4. **PR 只執行測試與編譯，不上傳或長期保留 Debug APK**；`main` 才會發布正式簽章 APK。
5. 新版 APK 上傳並驗證成功後，先保留上一版做臨時備份，再安全切換固定下載檔名為 `my-painter-latest.apk`，最後清除備份、其他 APK、舊 Releases 與原本的 PR APK Artifacts。失敗時保留上一版。
6. GitHub Releases 只保留 `latest`，其 APK 資產只會有 **1 個**。GitHub Actions 的建置日誌與 Gradle 相依套件快取仍依 GitHub 的個別保留設定管理，並不等同於 APK。

### 設定固定正式簽章（重要）

在 Repository Settings → Secrets and variables → Actions 新增：
- `KEYSTORE_BASE64`：私有 JKS 的 Base64 內容（不可提交到 GitHub）
- `KEYSTORE_PASSWORD`
- `KEY_ALIAS`
- `KEY_PASSWORD`

最新 `main` Workflow 會先驗證 JKS、alias、密碼，再使用同一把私鑰簽署 Release APK；透過 `apksigner verify --print-certs` 取得公開證書 SHA-256，並記錄至 GitHub Release 說明。如果之後簽章指紋意外改變，CI 會拒絕覆蓋既有正式版本。妥善備份 JKS 與密碼。

**請注意：**先前下載的 DEV 測試版使用 `com.mypainter.app.debug`，與固定簽章正式版 `com.mypainter.app` 是不同 App；兩者不能直接互相覆蓋，資料也不會自動搬移。首次安裝正式版後，後續只要使用相同 JKS、套件名稱且遞增 versionCode，就可以覆蓋更新。正式版不再使用 Debug APK 備援。

啟動圖示採繪畫主題的彩色畫冊、蘋果、畫筆與調色盤，包含 Android 圓形及自適應圖示。

## 程式碼位置

- `ShopCatalog.kt`：六區 36 品項向量描線資料
- `LineArtwork.kt`：**新圖源引擎**，直接將商品原圖放大，提取輪廓、色區、透明遮罩並處理描線與畫筆；`DrawingCore.kt` 保存舊資料結構以向下相容
- `DrawingScreen.kt`：36 色、觸控、模式切換、畫筆
- `ArtworkStore.kt`：本機作品 JSON 儲存、寫入暫存再替換
- `AudioGuide.kt`：TTS、提示聲及家長偏好
- `MainActivity.kt`：首頁、分類、作品集、家長設定

## 橫向繪畫介面

- 主畫面與畫畫頁以橫向模式（`sensorLandscape`）運作，允許裝置翻轉至左右兩種橫向方向。
- 首頁左側放置介紹與功能捷徑，右側以 2～3 欄展示超市六個主題區。
- 繪畫頁左側保持 **最大可容納的正方形畫布**，右側是獨立捲動的工具、36 色調色盤及畫筆粗細；手指畫畫不會觸發整頁捲動。
- 線稿放大 1.12 倍，所有觸控座標同步反向換算，維持描線與填色的位置準確。手機和平板均依螢幕比例調整畫布和側欄。
- 保留原有作品檔案及固定簽章 APK 更新方式。

## 圖稿來源修正

早期版本曾以 Android emoji 作圖，造成內部線條不足；現已替換為以下 36 張兒童線稿，原 Emoji 產圖方式不再供畫布使用。

## 兒童線稿圖庫（36 張）

2026-10-24 起，畫布改用真正的兒童著色圖稿，不再從 Emoji 像素自動推算不準確的外框。圖稿來自本專案製作的六張黑白著色頁，分別為水果、蔬菜、麵包甜點、飲品乳製品、雜貨與購物玩具，每組六張，共 36 張。

- 商品選擇與作品集直接顯示相同線稿縮圖，點入畫畫時不換圖。
- 每幅包含物體內部線條，例如葡萄果粒、玉米、麵包紋理、甜甜圈糖霜、收銀機按鍵、玩具車輪等，適合 4～8 歲描線與逐格上色。
- 圖形黑線像素切出獨立封閉色格；油漆桶只能對內部白色封閉格填色，畫筆限制在起點所在色格，內部線條仍然留在最上層。
- 36 張以離線壓縮線稿形式內建 App，不必額外下載，開圖前單元測試會逐張檢查線稿完整性。
- 橫向大畫布、36 色、作品存檔、原固定金鑰簽章 CI 保留。

註：舊版本以 emoji 產生的像素填色已保留在原 JSON 欄位，但無法完整對應新版線稿的每個色格。新版填色使用另外的色格編號，舊資料不會被刪除。
